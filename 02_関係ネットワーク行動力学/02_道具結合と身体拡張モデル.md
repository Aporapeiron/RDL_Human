# 02_道具結合と身体拡張モデル

*RDL Human / T3 / DRAFT v1.4*  
*Core v2.3同期 / Human固有仮説*

## 0. 目的

道具との結合が、行為可能域・取得情報・出力・危険・社会応答を変え、同じ人間SILNから異なる行動流向を露出させるというHuman側モデルを検討する。

## 1. Core接続

```text
human SILN ↔ tool / environment / other people RIB群
                         ↓ Purpose / B_tool
                      RIB_B
                         ↓ M_B
                         F
                         ↓
             Human-side Space / Flow model
```

旧 `interp(M_B^person, Tool)` のように道具を直接F入力へ置かず、道具との結合によって **RIBの成立条件が変わる**と扱う。

## 2. 結合強度

`κ` をHuman側の結合強度指標として残せる。

- 操作が身体化されている程度
- 出力がどれだけ拡張されるか
- 感覚フィードバックがどれだけ返るか
- 道具なしでの行動との差

を記述する補助量であり、Core Primitiveではない。

## 3. 装甲・拡張型

車・重機・防護具等では、質量・速度・出力・防護・到達可能域が変わる。

Human側で「自己境界が車体まで拡張する」と表現する場合、それは身体図式・責任範囲・侵入感・行為可能域等のモデルであり、Core `B` の拡張ではない。

```text
tool coupling
↓
physical / sensory / social RIB conditions change
↓
RIB_B' → F'
↓
Flow / behavior changes
```

## 4. 常時接続・透過型

スマートフォン等は、場所・時間・他者からの接触可能性を変える。

旧「境界融解」「24時間ξ流入」「熱H滞留」はHuman側の比喩としてのみ残し、Core定義には使わない。

実際の検査では、

- 通知頻度
- 中断回数
- 接触可能時間
- 睡眠前後の利用
- 注意切替
- 社会的要求
- 回復時間

等を別々の観測量として扱う。

## 5. 道具と行動表現

同じ道具でも、履歴・熟練・身体条件・社会規範・目的が異なれば `RIB_B / F / Flow` は異なりうる。

したがって「車に乗ると攻撃的になる」「スマホは必ず過覚醒を作る」と一般化せず、条件依存の仮説として耐久検査する。

## 6. 設計への接続

道具設計では、

- 出力拡張とフィードバックの非対称
- 中断・通知の制御可能性
- オフライン／休止可能性
- 誤操作時の破断コスト
- 他者へ外部化されるコスト

を耐久検査対象とする。

## 7. ξ

AI・ウェアラブル等の未整理な結合を `ξ` の内容と呼ばない。未モデル化領域は `unresolved / coverage` として保持し、有限Bで未回収関係が残るという条件のみをCore `ξ` とする。
