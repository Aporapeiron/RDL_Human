# 03_多重境界と認知勾配による性格生成

*RDL Human / T3 / DRAFT v1.2*  
*Core v2.3同期*

## 0. 目的

身体条件、他者との力関係、制度・規則、履歴等が行動コスト・到達可能性を変え、その場で反復されるFlowが性格表現として観測されるというHuman側仮説を記述する。

旧版の「多重のCore境界Bが性格を生成する」という読みは採用しない。

## 1. 関係条件

```text
human SILN
↕ bodily / social / institutional / tool RIB群
↓ Purpose / B_obs
RIB_B
↓ M_B
F
↓
Human-side cost landscape V / Space
↓
Flow
↓
observed personality expression
```

社会規範・身体限界・対人距離等は、Core Bではなく **Bで観測する対象側の拘束・関係条件**である。

## 2. 礼節・調整の創発仮説

次の条件では、礼節・予測交換・協調等が局所的に維持されやすい可能性がある。

1. 相互破断コストが高い
2. 反復接触がある
3. 関係維持利益がある
4. 相手の反応を予測する必要がある

これは「礼儀正しい人格」の本質説明ではなく、特定環境でその流向が安定する条件仮説である。

## 3. コスト地形

Human側の補助量として、

```text
V(x) = f(
  physical cost,
  social cost,
  learned expectation,
  resource,
  risk,
  goal,
  current state
)
```

を置ける。

旧 `V = Σ w_k interp(M_B, B_k, x)` のように社会的境界をCore Bとして直接interpへ入れない。

## 4. 性格表現

同じ人でも身体、道具、相手、安全性、匿名性、反復性等が変わればFlowが変わりうる。

したがって性格ラベルは、

> **特定の測定Bで反復観測された流向の圧縮記述**

として扱う。

## 5. 耐久検査

環境条件を変えても同じFlowが残るのか、反転するのか、どの条件が主要かを揺らし・境界変更・履歴検査で調べる。
