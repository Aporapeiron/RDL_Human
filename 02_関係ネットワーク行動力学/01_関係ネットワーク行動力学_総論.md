# 01_関係ネットワーク行動力学_総論

*RDL Human / T3 / DRAFT v1.2*  
*Core v2.3同期*

## 0. 核心テーゼ

> **人間の行動・性格表現は、個体内部の固定部品だけで決まるのではなく、身体・道具・他者・制度・履歴との相互作用と、現在の有限構造断面によって形成される局所的な流向として観測できる。**

## 1. Core接続

Human側の関係配置 `W_ij` は、対象間の関係を記述する補助モデルであり、CoreのRIBそのものではない。

```text
human / group SILN
↕
身体・道具・他者・制度・履歴に関する {RIB_i}
↓ Purpose / B
RIB_B
+
M_B
↓
F = interp(M_B, RIB_B)
↓
Human側の Interpreted Space_B / C_B
↓
Flow
↓
Observable phenotype
```

旧 `interp(M_B^person, W_ij, EFP)` は採用しない。`W_ij` は関係配置モデル、`RIB_B` は現在取得する相互作用断面、`F` は解釈後状態として分離する。

## 2. Human側の3層生成モデル

### 第1層：関係配置

- 身体条件
- 道具・テクノロジー
- 他者・集団
- 制度・法律
- 言語
- 個体史
- 現在状態

これらは、相互作用RIB群を形成する条件でもある。

### 第2層：解釈された認知空間

`Space_B`、`C_B`、距離、障壁、到達可能域等を、現在の `M_B / RIB_B / F` から構成するHuman側の二次モデルとして扱う。

### 第3層：Flow

接近・回避・同期・維持・探索・迂回等の反復的傾向をFlowとして記述する。

性格ラベルはFlowそのものではなく、特定Bからの圧縮観測である。

## 3. 主要仮説

### 3.1 身体制約とコスト地形

身体状態は、移動・衝突・回復・感覚取得の可能域を変え、後続するRIB条件と行動選択を変える。

### 3.2 道具結合

車、スマホ、AI、重機等との結合は、到達可能性・出力・取得情報・遅延・社会応答を変え、新しいRIB条件を作る。同じ道具でも `M_B` と履歴が異なれば `F` とFlowは分岐しうる。

### 3.3 場の相対剛性

相互破断コスト、反復接触、関係維持利益が高い場では、礼節・調整・予測交換等が安定流向として残る可能性がある。

## 4. 性格モデルとの関係

Big Five、MBTI、社会的ラベル等は、人間のSILN内部に埋め込まれた独立部品ではない。

```text
human dynamics
↓ specific measurement B
observed responses
↓ compression
trait / type label
```

RDL_Humanは、各ラベルがどの条件で安定し、どの条件で反転・破断するかを比較する。

## 5. 適用上の注意

`Space_B / C_B / Flow / W_ij` はHuman側の仮説変数である。Core記号と同等の身分を持たず、既存心理学・社会学理論との対応も操作的マッピングに留める。
