# 実効拘束場と重力勾配

*RDL Human / T3 / DRAFT v2.1*  
*Human固有モデル / Core v2.3同期*

## 0. 核心テーゼ

> **実効拘束場 `C` は、選択肢・行動・移動の「進みにくさ／維持しにくさ」を圧縮するHuman側のモデルであり、その勾配を「重力」と呼ぶのは直観的メタファーである。**

「自由という実体は存在しない」と存在論的に断定せず、特定Purposeで観測される選択可能性を拘束地形として再記述する。

## 1. Core接続

```text
human / group SILN
↕ RIB群
↓ Purpose / B
M_B / RIB_B
↓
F
↓
Human-side C(x | F, conditions)
↓
Flow candidate
```

`C_B` はCore Primitiveではない。添字Bは「このBで構成した補助モデル」を示す。

## 2. 実効拘束度

```text
C(x) = f(
  physical effort,
  risk,
  time,
  resource,
  social sanction,
  learned skill,
  information,
  uncertainty,
  goal value,
  current bodily state
)
```

低Cほど必ず選択されるとは限らない。目的価値、探索、規範、長期予測等との相互作用を残す。

## 3. 重力メタファー

```text
G(x) ~ -∇C(x)
```

は、低拘束方向へ流れが偏る場合のHuman側近似である。物理重力との同一性を主張しない。

獣道、習慣、制度、UI、交通等で、反復利用が次のコスト地形を変える正のフィードバックを記述するのに使える。

## 4. 社会現象への利用

貨幣、法、言語、習慣、依存等をすべて同一メカニズムと断定せず、「どのコストを下げ／上げ、何を次の選択条件へ残すか」という比較面へ置く。

心理負荷をCore `H`、未知を`ξ`へ直接変換しない。

## 5. 最小循環

```text
RIB_B(t)
↓
F(t)
↓
Human-side C_t / Flow_t
↓ action
interaction conditions change
↓
RIB_B(t+Δ)
```

行動履歴が技能・制度・環境を変えれば、次のC地形も変化する。

## 6. 一文圧縮

> **実効拘束場は、相互作用と解釈の結果として現れる行動上の進みにくさをHuman側で圧縮するモデルであり、「重力」は拘束勾配に沿う偏りを表すメタファーである。**
