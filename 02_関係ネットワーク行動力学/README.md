# 02_関係ネットワーク行動力学

*RDL Human / T3 / Core v2.3同期*

## 一文定義

> **人間の行動・性格表現を、固定属性ではなく、身体・道具・他者・制度・履歴との相互作用RIB群が、現在の構造断面 `M_B` を通して解釈されることで生じる局所的な流向として記述するHuman固有モデル。**

## 基本骨格

```text
human / group SILN
↕
身体・道具・他者・制度・履歴に関する RIB群
↓ Purpose / B
RIB_B + M_B
↓
F = interp(M_B, RIB_B)
↓
Human側の認知空間 / 実効拘束場 C_B
↓
Flow
↓
反復観測された表現型
```

`W_ij`、`Space_B`、`C_B`、`Flow` はHuman側のモデル変数であり、Core Primitiveではない。同じ環境刺激が誰にとっても同一 `RIB_B` / `F` になるとは仮定しない。
