# SSDからの翻訳 — pre-v2.3 archive

このディレクトリは、旧 **構造主観力学（SSD）** の人間モジュール15本を **RDL v2.0 時点の語彙**へ翻訳した履歴アーカイブである。

> **現行 RDL_Core v2.3 / RDL_Human の定義根拠として直接使用しない。**

当時の翻訳には、現在廃止・変更された次の対応が含まれる。

```text
EFP / 素流圧                    → 現行では RIB / RIB_B へ再翻訳が必要
B が対象・自己境界を生成する     → 現行Core Bとは不一致
M_B = 人格・主観構造そのもの      → 現行では有限構造断面
未知 / 外集団 / 新奇性 = ξ        → 不採用
心理的熱・情動エネルギー = Core H → 不採用
神経物質 = Core変数              → 不採用
```

現行化する場合は、少なくとも次へ再マッピングする。

```text
SILN ↔ {RIB_i}
      ↓ Purpose / B
M_B + RIB_B
      ↓
F = interp(M_B, RIB_B)
      ↓
必要な場合のみ E / H / θ
```
