# SSDからの翻訳（旧SSD人間モジュール群のRDL v2.0翻訳アーカイブ）

本体アクティブ層（`01_基層構造_神経力学/`〜`06_対話_倫理_社会生態系/`）への直接配備ではなく、将来の人間モデル統合・詳細化のための参照原典として本フォルダーに独立保持されます。

## ■ 主な用語翻訳対応表

- **構造主観力学（SSD）** $\to$ **関係力学言語（RDL）/ 人間モジュール**
- **主観的構造** $\to$ **有限関係拘束構造 $M_B$**
- **主観的境界** $\to$ **有限境界 $B$**
- **整合慣性** $\to$ **拘束保持慣性 $I(M_B)$**
- **素流圧（Elementary Flux Pressure）** $\to$ **素流圧（$EFP$: 外部作用入力束）**
- **意味圧（外的/内的）** $\to$ **作用圧（$F$ / $EFP$）**
- **未知意味圧** $\to$ **未知作用圧（未解釈 $EFP$ / 未回収関係 $\xi$）**
- **内部熱 $E$** $\to$ **不整合 $E$（未解消熱 $H$）**
- **跳躍（Leap）** $\to$ **閾値 $\theta$ 突破に伴う再編相 $M_\Delta$ を経た $M_B \to M_B'$ 更新**
