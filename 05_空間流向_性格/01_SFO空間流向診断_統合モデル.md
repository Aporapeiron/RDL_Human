*RDL Human / T3 / DRAFT v1.1*  
*Human固有モデル / Core v2.3同期*

## 0. 位置づけ

> **SFO（Space Flow Orientation）は、性格を固定型として分類せず、特定条件で反復して現れる探索・維持・同期・防衛等の行動流向を記述するHuman側モデルである。**

SFOは診断学上の確定尺度でもCore変数でもない。

```text
human SILN

flow profile
```

## 2. 4つの基本流向候補

- **Explore** — 新奇な課題・外部機会へ接近しやすい
- **Maintain** — 既存目標・手順・関係を維持しやすい
- **Sync / Connect** — 他者との協調・同期・ケアへ向かいやすい
- **Alert / Defend** — 脅威情報へ注意し、距離確保・防衛へ向かいやすい

これらは排他的な人格型ではなく、同一個体で状況により同時・交互に現れうる。

## 3. 旧対応の修正

```text
unknown / novelty ≠ ξ
self-boundary ≠ Core B
alert threshold ≠ Core θ
neurotransmitter level ≠ SFO score
```

DA / 5-HT / OXT / NA等との対応は生物学的接続候補としてのみ扱い、「高DA＝探索型」のような人格同定をしない。

## 4. 観測変数

SFOの測定では、

- 接近／回避頻度
- 探索開始条件
- 計画保持
- 対人同期
- 脅威時の切替
- 回復時間
- B・場面変更時の反転

等を使える。

## 5. 他尺度との関係

Big Five / MBTI等との対応は、測定結果同士の比較候補であって概念等号ではない。それぞれの測定Function・妥当性・coverageを保持する。

## 6. 一文圧縮

> **SFOは、人間SILNの内部部品を測るのではなく、特定相互作用条件と測定Bのもとで現れる行動流向を圧縮するHuman側の観測モデルである。**
