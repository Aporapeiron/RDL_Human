# 03_MBTI_SILN項目分解

*RDL Human / T3 / DRAFT v1.1*  
*ファイル名は履歴上維持 / Core v2.3同期*

## 0. 目的

MBTIの4指標（E/I, S/N, T/F, J/P）を固定的な人間構造として採用せず、**自己報告・選好・状況依存の応答を整理する観測断面候補**としてRDL上へ配置する。

MBTIタイプをSILNの内部部品やCore変数へ変換しない。

## 1. 翻訳候補

| 軸 | Human側の比較候補 |
|---|---|
| E / I | 外部相互作用への接近・回復・注意配分の傾向 |
| S / N | 具体的近接情報と抽象・遠距離関係への注意配分 |
| T / F | 判断時に用いる評価基準・対人影響・規則の重みづけ |
| J / P | 早期収束・計画保持と、未確定維持・再探索の傾向 |

これらは一つのHumanモデルであり、Core `B / M_B / RIB_B / F` と一対一対応しない。

## 2. RDL接続

```text
human SILN
↕ RIB群
↓ assessment B
responses
↓ scoring Function
MBTI label
```

ラベルは測定Functionの出力であり、人間そのものではない。

## 3. 比較上の注意

MBTIとBig Fiveを同等の科学的身分として扱わない。RDL上では、それぞれが何を測り、どのBで再現し、どこで破断するかを別々に検査する。
