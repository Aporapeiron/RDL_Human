# 04_身体_移動_流れ

*RDL Human / T3 / Core v2.3同期*

## 一文定義

> **身体循環・空間移動・思考・情動に見られる「流れ」の類似を、Human側の操作的モデルとして比較し、身体と環境の相互作用から移動・閉塞・回復を記述する。**

## 適用規律

「流体」「通水」はHuman固有のモデル比喩であり、異なる現象が物理的に同一流体であるとは主張しない。

```text
body / agent SILN
↕ RIB群
B → M_B / RIB_B → F
↓
Human側の Flow model
```

- `SILN分解` はSILNをBから生成する操作ではない。SILNとして対象化した系の構成・機能を有限に展開する意味で使う。
- 新奇刺激を `ξ流入` と呼ばない。
- Human側の閉塞・負荷を Core `H` と自動同一視しない。
