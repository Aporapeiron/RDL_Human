# 03_関係力学的幸福モデル

*RDL Human / T3 / DRAFT v1.1*  
*Human固有仮説 / Core v2.3同期*

## 0. 位置づけ

> **Well-beingを単一快楽量としてではなく、身体・移動・思考・感情・他者関係における持続可能な活動、回復、関係循環、選択可能性の組合せとして探索するHuman側モデル。**

本稿の「通水」「詰まり」「熱」はHuman固有の操作的比喩であり、Core `ξ / H` と同一ではない。

## 1. 三つの観測軸

### 1. 通水性 / 回復可能性

身体・認知・情動・関係のいずれかが長期的に閉塞せず、活動と休止を切り替えられるか。

### 2. 適度な新奇性・挑戦

旧「healthy ξ inflow」は採用しない。新奇刺激や挑戦はRIB条件として記述する。

```text
novel interaction conditions
↓ B
RIB_B^novel
↓
F / action / learning response
```

新奇性の量はHuman側の観測変数であり `ξ` ではない。

### 3. 再構成可能性

状況変化に応じて、習慣・解釈・行動候補を局所更新または再構成できる余地があるか。

Human側の「心理的境界の柔軟さ」とCore `B` を同一視しない。

## 2. 不調の読み方

不調を一つの「高H」へ還元せず、

- 身体条件
- 行動可能域
- 睡眠・休止
- 反復的な未解決課題
- 社会的孤立
- 強制的な関係拘束
- 目標と資源の不一致

等を別々の条件として記録する。

## 3. RDL接続

```text
human SILN
↕ bodily / social / environmental RIB群
↓ Purpose / B
M_B / RIB_B / F
↓
Human well-being indicators
↓
維持 / 変形 / 回復 / 破断候補
```

このモデルは医学的診断・治療規則ではなく、関係条件を比較するためのT3仮説である。
