# RDLによる言語・共有文脈・言語変化の関係モデル

*RDL Human / T3応用候補 / LANGUAGE / DRAFT v0.2*  
*同期基準: RDL_Core BASE / SPEC v2.3*

## 0. 目的

言語を、意味を完全内包した記号列ではなく、**話者・聞き手・媒体・環境・履歴・制度が作る相互作用の中で成立する有限な解釈過程**として扱う。

本稿では、

- 主語・目的語等の省略
- 共有文脈
- 「空気」
- 言語ごとの明示性
- 言語習得・変化
- 制度と共同体

をRDL上で比較可能にする。

## 1. 基本位置づけ

言語体系・話者・共同体・制度等は、用途に応じてSILNまたはSILN群として対象化できる。実際の発話イベントでは、

```text
話者 / 聞き手 / 媒体 / 場 / 履歴 / 制度
            ↕
         RIB群
            ↓ Purpose / B_lang
RIB_B^lang = Section_B({RIB_i^lang})
            ↓
F_lang^A = interp(M_B^A, RIB_B^lang)
F_lang^B = interp(M_B^B, RIB_B^lang)
```

となる。

音声・文字・身振り・視線・場所・社会的役割・直前の会話等を旧 `EFP_lang` のような一つの外生入力へ束ねず、**言語イベントを成立させるRIB群**として扱う。

## 2. 明示情報と文脈情報

発話で明示される信号と、発話外から参照される情報源を区別する。

```text
explicit channel
  音声 / 文字 / 明示された身振り

contextual channel
  視線 / 場所 / 直前履歴 / 人間関係 / 制度 / 共有作業 / 予測
```

両者はいずれも相互作用条件であり、Bのもとで必要な部分が `RIB_B^lang` へ入る。

「食べた？」のように主語・目的語が省略されても、文脈側の相互作用断面から十分な差別化が得られれば通信は成立する。

> **非明示 ≠ 情報不存在。非明示とは、必要な差別化を発話信号以外の関係から取得する運用である。**

## 3. 共有文脈

共有文脈は、二者が同一 `M_B` を持つ状態ではない。

> **異なる構造断面を持つ複数主体が、現在のRIB_Bから行動・意味・予測を維持できる程度に近い `F` を形成できる状態。**

```text
RIB_B^lang
 ├─ interp(M_B^A, ...) → F_A
 └─ interp(M_B^B, ...) → F_B

compatibility(F_A, F_B) が実用域にある
→ 通信継続
```

完全一致を要求しない。有限Bには常に未回収関係 `ξ` が残る。

## 4. 「空気」の暫定的位置づけ

「空気」を独立実体や固定SILNとして置かない。

暫定的には、

> **その場の参加者が、明示信号以外のRIB_Bから推定している局所的な関係拘束・期待・禁忌・役割の候補。**

とする。

「空気を読む」は、

```text
RIB_B^lang
↓ M_B
role / expectation / taboo / likely response の推定
↓
F_air candidate
```

として扱う。推定にはcoverage不足・誤読がありうるが、それらを自動的に `ξ` と同一視しない。

## 5. 明示化圧

補助量 `ExplicitPressure_B(x)` を、ある情報を明示しない運用がどれだけ維持困難かを表すHuman側の指標として使える。

```text
ExplicitPressure_B(x)
≈ f(
  使用頻度,
  誤認率,
  誤認コスト,
  文脈からの復元可能性,
  学習コスト,
  修復コスト,
  制度上の要求
)
```

`ξ` を数値入力項として置かない。未回収関係が存在することは、この補助モデルのcoverage限界として別保持する。

## 6. 言語使用のフィードバック

言語使用の結果は、次の相互作用条件を変える。

```text
RIB_B^lang(t)
↓
F_lang(t)
↓
発話 / 行動 / 修復 / 学習
↓
関係・使用頻度・制度・期待が変化
↓
{RIB_i^lang(t+Δ)}
↓ B_lang
RIB_B^lang(t+Δ)
```

したがって「みんなが使う」は単なる結果ではなく、次の学習・理解可能性を変える環境条件になる。

## 7. 言語変化

言語変化を目的を持つ最適化として固定しない。

```text
表現変異
↓ 使用
相互作用・理解・誤読・修復
↓
使用頻度と関係条件の変化
↓
次世代のRIB条件・学習条件へ
```

必要な場合、同一の `M_B` で後続 `F` を比較し `E = Δ(F,F')` を置けるが、言語変化のすべてをCore `E/H/θ` に還元しない。

## 8. 言語多様性

異なる言語は、何を明示し何を文脈側へ委ねるか、どの関係を安定して再利用するかが異なる。

RDLは「どの言語が優れているか」を一つの尺度で決めず、Purpose / Bごとに、

- 誤認率
- 修復コスト
- 学習コスト
- 社会関係維持
- 作業効率
- 制度との適合
- coverage

等を比較する。

## 9. Coreとの対応

```text
SILN      : 話者・共同体・言語体系・制度等を対象化した有限構造
RIB       : 発話・視線・行動・媒体・環境等の相互作用束
B         : 現在の問い・場・時間・対象範囲
M_B       : 解釈側の有限構造断面
RIB_B     : 現在扱う言語相互作用断面
F         : 形成された意味・予測・行動候補
ξ         : Bで未回収の関係が残る条件
```

旧 `EFP_lang → F_lang → E_lang → H_lang` は現行標準形として採用しない。

## 一文圧縮

> **言語とは、記号単体に意味が閉じているのではなく、SILN群がRIB群を介して相互作用し、Bで取得された言語断面を各M_Bが解釈することで、その都度意味・予測・行動が形成される関係運動である。**
