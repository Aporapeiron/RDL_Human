# 04_性格_特性_身体系

*RDL Human / T3 / DRAFT v1.1*  
*翻訳 = role mapping / Core v2.3同期*

## 0. 分類軸

特性論、タイプ論、身体拡張論を、Human側のFlow・道具結合・測定断面モデルと比較する。

## 1. Big Five

Big Five因子をSILN内部パラメータへ分解するのではなく、特定の測定手続きから得られる統計的な特性記述として保持する。

RDL側では、同じ個体についてB・場面・RIB条件を変えたとき、各スコアと行動応答の関係がどこまで維持されるかを検査する。

```text
Big Five factor ≠ Core variable
Neuroticism ≠ E→H conversion rate
Openness ≠ weight toward ξ
```

## 2. ユング／MBTI

MBTIの指標をCore B操作やM_B構造へ直接対応づけない。自己報告・選好・分類Functionの出力として扱い、再現範囲や用途を別に検査する。

Big FiveとMBTIを同じ科学的身分へ揃えない。

## 3. マクルーハン／身体拡張

道具・媒体によって感覚取得・行為可能性・社会応答が変わる点をRIB条件の変化として比較できる。

```text
tool / medium coupling
↓
RIB conditions change
↓ B
RIB_B / F / behavior changes
```

「media changes Core B」「cool media = ξ補完量」のような同一化は採用しない。

## 4. 翻訳原則

性格ラベル・媒体概念をRDLの基底変数へ還元せず、異なる測定・理論がどの現象を切り取っているかを比較する。
