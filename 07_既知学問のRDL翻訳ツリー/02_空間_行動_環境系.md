# 02_空間_行動_環境系

*RDL Human / T3 / DRAFT v1.1*  
*翻訳 = role mapping / Core v2.3同期*

## 0. 分類軸

場・環境・行為可能性・選択アーキテクチャ・相互依存を扱う理論を、Human側の `C / Flow` モデルと比較する。

`C / Flow` はHuman固有変数であり、既存理論を統一する物理量ではない。

## 1. レヴィン場の理論

Life Space、valence、boundary、tension、behavior とHuman側の空間・拘束・流向モデルに類似する記述面を比較できる。

ただし、

```text
Tension = Core H
psychological boundary = Core B
Life Space = C_B
```

とは同一視しない。

## 2. ギブソンのアフォーダンス

身体と環境の関係から行為可能性が変わる点を、

```text
organism SILN ↔ environmental RIB群
↓
Human-side action possibility / cost model
```

と比較できる。

身体を `M_B`、環境を単一 `E` と等置しない。

## 3. 行動経済学・ナッジ

選択肢配置、デフォルト、情報提示、コスト等が行動分布を変えることをHuman側拘束地形と比較する。

「バイアス = SILNそのもの」「ナッジ = -∇Cを作る」と断定せず、どの条件でその近似が有効かを検査する。

## 4. ゲーム理論

利得行列・均衡・反復ゲームと、複数SILN間の相互作用履歴・行動安定性を比較する。

```text
SILN_A ↔ RIB_AB ↔ SILN_B
↓ repeated interaction
response patterns / strategy stability
```

ナッシュ均衡を「E/HがゼロのSILN定常状態」と同一視しない。

## 5. 翻訳原則

既存理論の数学・定義をRDL比喩で置き換えず、対応候補・非対応領域・coverageを残す。
