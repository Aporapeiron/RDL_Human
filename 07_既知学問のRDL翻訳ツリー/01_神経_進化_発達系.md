# 01_神経_進化_発達系

*RDL Human / T3 / DRAFT v1.1*  
*翻訳 = role mapping / Core v2.3同期*

## 0. 分類軸

発達・進化・欲求・時間スケールを扱う既存理論を、Human側の4層モデルやRDLの相互作用記述と比較する。

**理論間の等号・完全同型を主張しない。**

## 1. マズロー欲求段階説

マズローの欲求分類とHuman側の身体・安全・所属・承認・探索等の観測軸には比較可能な部分がある。

ただし、

```text
生理欲求 = 第1層
所属欲求 = Affiliate
自己実現 = ξ探索
```

とは置かない。

欲求段階説の階層性と、Human側の時間スケール分解がどの条件で一致／不一致になるかを検査する。

## 2. ピアジェ

schema / assimilation / accommodation / equilibration と、RDLの有限構造・再解釈・再構成を比較できる。

```text
schema          ↔ finite internal model candidate
assimilation    ↔ existing modelでの処理・学習候補
accommodation   ↔ structural reorganization candidate
equilibration   ↔ state stabilization candidate
```

`schema = M_B`、`accommodation = H≥θ`、`equilibration = SILN` のような等号対応は採用しない。

## 3. 進化心理学・行動生態学

長期的な選択履歴と、現在の行動・生理・認知傾向の関係を比較する。

Human側の4層モデルやExplore / Alert等は翻訳補助変数であり、進化心理学上のモジュールと同一ではない。

## 4. 翻訳原則

- 原理論の概念を保持する
- RDL側は近い役割だけ示す
- 不一致・非対応を残す
- 新奇性を `ξ`、生理負荷をCore `H` に変換しない
- Human側4層モデルを科学的発達階層として実体化しない
