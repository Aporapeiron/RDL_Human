## 0. 分類軸

愛着・社会関係・制度・疎外等を、Human側の関係結合・拘束・回復・Flowモデルと比較する。

心理的／社会的な「境界」はCore `B` そのものではない。

## 1. 愛着理論

内的作業モデル、安全基地、愛着パターン等と、Human側の関係予測・接近／回避・回復・探索条件に比較可能な面がある。

ただし、

```text
internal working model = M_B
secure base = H reset point
attachment style = B_self operation
```

とは同一視しない。

```text
child / caregiver SILN群
↕ repeated social RIBs
↓
learning / expectation / approach / avoidance patterns
```

として関係履歴を見る。

## 2. マルクス：物象化・疎外

貨幣・商品・労働関係・制度が行動可能域や選択コストへ与える影響をHuman側 `C / Flow` モデルと比較できる。

「資本 = 重力源」と存在論的に同一化せず、どの制度条件が何の経路を低／高コスト化するかを具体的に記録する。

## 3. 翻訳原則

- 原理論の概念を保持する
- Human側モデルは比較の補助線として使う
- 心理境界 ≠ Core B
- 未知・外集団 ≠ ξ
- 緊張・苦痛 ≠ Core H
- 完全同型を主張しない
