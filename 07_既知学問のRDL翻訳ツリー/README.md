# 07_既知学問のRDL翻訳ツリー

*RDL Human / T3 / Core v2.3同期*

## 目的

既存の心理学・認知科学・神経科学・社会学等を、RDLで**科学的に統一・同一化するのではなく**、比較・再検査可能な共通座標へ暫定配置する。

## 翻訳規律

翻訳は同一性主張ではない。

```text
既存理論の概念
   ↓ role mapping
SILN / B / M_B / RIB / RIB_B / F / E / H ... のどの役割に近いか
   ↓
一致点 / 不一致点 / 非対応領域を保持
```

特に、

```text
感覚入力 ≠ 自動的に RIB_B
予測誤差 ≠ 自動的に Core E
自由エネルギー ≠ Core H
ノイズ / 無意識 / 未知 ≠ ξ
Markov blanket ≠ Core B の完全同義語
```

とする。

## 現在の分類

- `01_神経_進化_発達系.md` — 時間スケール・発達・適応の比較
- `02_空間_行動_環境系.md` — 環境・行動・拘束地形の比較
- `03_熱_誤差_情動系.md` — 誤差・緊張・情動モデルの比較
- `04_性格_特性_身体系.md` — 特性・身体拡張・流向の比較
- `05_境界_愛着_社会系.md` — 愛着・境界・社会関係の比較

## 現行RDL側の最小骨格

```text
SILN ↔ {RIB_i}
      ↓ Purpose / B
M_B + RIB_B
      ↓
F = interp(M_B, RIB_B)
      ↓
必要に応じて E / H / θ
```

旧 `EFP → F → E → H` の一列対応は採用しない。

> **本ツリーの目的は、既存理論をRDLへ回収することではなく、異なる理論が何を見て何を見落とすかを同じ検査面へ置くことである。**
