# 03_熱_誤差_情動系

*RDL Human / T3 / DRAFT v1.1*  
*Core v2.3同期*

## 0. 分類軸

既存理論の「予測差・緊張・葛藤・調整・回避・行動」を、RDLの共通座標へ暫定配置する。

> **ここで行うのは概念同一化ではなく role mapping である。**

特に、既存理論の用語をCore `E / H / B / ξ` へ直接等号で結ばない。

## 1. 自由エネルギー原理（FEP）

### 既存理論側

FEP・active inferenceでは、感覚・生成モデル・予測・行動等を独自の数学体系で扱う。

### RDL側の比較

```text
organism / model system as SILN candidate
↕ sensory / action / environment RIB群
↓ Purpose / B
RIB_B
↓ M_B
F
```

比較上、

- sensory input はRIB形成の一部になりうるが `RIB_B` そのものとは限らない。
- variational free energy / prediction error をCore `E` と同一視しない。
- FEPの内部状態を `M_B` と一対一同一視しない。
- Markov blanket とCore `B` は概念上の役割が異なり、完全同義ではない。

共通点・差異を保持したまま比較する。

## 2. 精神分析・防衛機制

フロイト的な「葛藤・防衛・昇華」等を、Human側では、

- 競合する価値・行動候補
- 回避・再解釈・抑制
- 社会的に許容される行動経路への変換

として記述候補にできる。

ただし、

```text
Id = 基層
Ego = M_B
Superego = B_social
unconscious = ξ
libido = Core H
```

のような同一化は採用しない。

「熱」「放熱」はHuman側の比喩として使う場合があるが、Core `H` は未解消差分の履歴として別定義する。

## 3. アドラー的補償

「理想と現状の差」「補償」「目標への行動」を、

```text
current interpretation / target representation
↓ compare
Human-side discrepancy
↓
action / learning / reorganization
```

として比較できる。

理想表象と現状表象をそれぞれCore `M_B` として存在論的に置かず、同一有限モデル内の候補表象として扱う。

## 4. 翻訳原則

既存理論をRDLへ翻訳するときは、

1. 原理論の用語と数学を保持する。
2. RDL側では役割対応候補だけを書く。
3. 等号ではなく「近い役割」「非対応」を記録する。
4. noise / unknown / unconscious を `ξ` に押し込まない。
5. Human側の熱比喩をCore `H` に昇格させない。

> **翻訳の成功とは、同じ言葉へ潰すことではなく、差異を残したまま比較可能にすることである。**
