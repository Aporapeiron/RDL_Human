*RDL Human / T3 / Core v2.3同期*

## 一文定義

> **複数の人間・集団・制度をSILN / SILN群として対象化し、対話・教育・規範・地域循環で生じるRIB群を有限に記述しながら、共同理解・破断回避・社会的循環を検査する応用領域。**

## 適用規律

「共同分解」「放熱」「自己境界」「社会重力」等はHuman側の操作語であり、Core Primitiveではない。

```text
SILN_A ↔ RIB_AB ↔ SILN_B
          ↓ Purpose / B
       RIB_B(section)
          ↓
interp(M_B^A, RIB_B) / interp(M_B^B, RIB_B)
```

同じ対話でも双方の `F` は一致するとは限らない。共有は「同一M_Bになること」ではなく、行動・意味・予測を維持できる程度の局所整合として扱う。

倫理文書はRDLから唯一の正解を演繹するものではない。不可逆破断・強制・情報非対称・外部化されたコスト等を可視化する検査枠として用いる。
