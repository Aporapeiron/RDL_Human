# 03_認知_情動_放熱

*RDL Human / T3 / Core v2.3同期*

## 一文定義

> **快・笑い・洞察・葛藤・主観時間などを、RIB_Bから形成される解釈、未解消差分、処理負荷、身体反応、再構成の関係として探索するHuman固有仮説群。**

## 重要な区別

```text
Humanの「熱」「放熱」「通水」 = 操作的比喩 / Human変数
Core H = 未解消Eの履歴的残留を扱うCore記号
ξ = 有限Bで未回収関係が残る条件
未知刺激・新奇性・ノイズ・心理負荷 ≠ ξ
```

したがって「ξが流入して熱Hになる」「感情はCore Hそのもの」とは置かない。Core `E / H / θ` を使う場合は、何を `F` と比較し、何を未解消差分として蓄積しているかを明示する。
