# 03_時間感覚とξ残存ダイナミクス

*RDL Human / T3 / DRAFT v1.1*  
*ファイル名は履歴上維持 / Core v2.3同期*

## 0. 修正された位置づけ

旧版では主観時間を「ξ流入密度」とCore `H` の関数として置いた。現行ではこの対応を採用しない。

> **主観時間は、注意配分、イベント密度、新奇性、予測可能性、待機・目標状態、身体状態、記憶形成等の関係から生じるHuman側の観測量として扱う。**

`ξ` は新奇刺激や未知情報の量ではない。

## 1. Human側の補助モデル

```text
SubjectiveTimeRate
≈ f(
  attention load,
  event density,
  novelty,
  prediction / controllability,
  waiting state,
  bodily state,
  memory encoding,
  task engagement
)
```

これはCore式ではなくHuman側の仮説である。

## 2. RDL接続

```text
human SILN ↔ RIB群
          ↓ Purpose / B_time
       RIB_B
          ↓ M_B
          F
↓
注意・イベント・行動・身体状態のHuman側指標
↓
主観時間報告 / 行動指標
```

フロー状態、退屈、待機、苦痛等で主観時間が異なるという仮説は、`RIB_B / F` とHuman側の注意・行動指標から検査する。

## 3. 年齢との関係

「年齢が上がるほどξが減るから時間が速くなる」とは置かない。経験の反復、新奇性、記憶密度、生活構造、注意の向け方等が変化する可能性を個別に検査する。

## 4. ξの役割

どれほど詳細な時間モデルを作っても、Bで回収されない関係は残る。これが `ξ` の身分であり、式の中で数える心理量ではない。
