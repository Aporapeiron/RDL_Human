# 02_アハ体験と認知跳躍モデル

*RDL Human / T3 / DRAFT v1.1*  
*Core v2.3同期*

## 0. 一文定義

> **アハ体験を、既存の解釈・探索経路では処理しにくかった関係が、別の構造候補・表現・関係づけによって急速に再構成され、後続の解釈差が大きく減る現象として扱う。**

旧「ξとCore Hが蓄積し、θを越えるとCore Bが跳躍する」という定義は採用しない。

## 1. 基本フロー

```text
RIB_B / problem conditions
↓
既存 M_B で探索
↓
F_1, F_2, ...
↓
差分・未解決制約が残る
↓
候補展開 M_Δ
↓ 検査・選別
M_B'
↓ 同条件を再解釈
F_new
↓
差分縮小 / 新しい予測可能性 / 「わかった」感
```

Core `H ≥ θ → M_Δ` を使える場合もあるが、洞察現象の全てをこの条件へ還元しない。

## 2. Human側の4段階

1. **探索** — 既存の表現・ルール・関係づけを試す。
2. **行き詰まり** — 同じ探索が循環し、未解決制約が残る。
3. **再構成候補の出現** — 表現、対象化、関係づけ、スケール等が変わる。
4. **再解釈と定着** — 新しい候補で問題を再評価し、後続の予測・行動が改善する。

Human側で「境界が変わった」と表現する場合、それは認知フレーム・対象化・注意配分等の変化を意味する。Core `B` を心理実体として直接変化させる意味ではない。

## 3. 快との関係

洞察に伴う快は、差分縮小、探索終了、予測可能性の増加、社会的確認等の複合候補として扱う。神経伝達物質との対応は検査可能な接続候補に留める。

## 4. 耐久検査

段階的洞察、誤った確信、後から崩れる洞察、他者から答えを与えられた場合等でもモデルが機能するかを検査する。
