# 04_中核葛藤と未知意味圧反応

*RDL Human / T3 / DRAFT v1.1*  
*Core v2.3同期*

## 0. 一文定義

> **葛藤を、同じ相互作用断面に対して複数の構造候補・価値拘束・行動予測が競合し、出力選択や再構成が難しくなるHuman側の状態として扱う。未知への反応は、未経験な相互作用条件に対する警戒・探索・再解釈の時間発展として扱う。**

未知刺激を `EFP_unknown` や `ξ` と同一視しない。

## 1. 古い構造候補と新しい構造候補

人間そのものを二つの `M_B` に分裂させるのでなく、一つの有限記述の内部で競合する候補モデル・拘束として扱う。

```text
RIB_B^event
↓
current finite structure M_B
 ├─ candidate model old → F_old / action A
 └─ candidate model new → F_new / action B
↓
conflict / switching cost / delayed action
```

過去に有効だった候補を全削除する必要はない。用途・状況に応じて再利用可能な局所モデルとして保持し、必要ならT1再構成で優先関係を更新する。

## 2. 未経験相互作用への二段階仮説

### 高速応答

- 注意の集中
- 警戒
- 既知カテゴリへの暫定分類
- 回避・停止・確認

### 低速応答

- 追加観測
- 他者からの情報取得
- 新しい関係候補の展開
- 検査・選別
- 必要な場合の `M_Δ → M_B'`

```text
unknown interaction conditions
↓ B
RIB_B^unknown
↓ M_B
F_initial
↓ additional interaction / observation
F_later
↓
維持 / 修正 / 再構成
```

## 3. Human側の負荷

競合・警戒・切替困難に伴う緊張を「熱」と呼ぶ場合、それはHuman固有の負荷比喩である。Core `H` を使うなら、どの `E` がどの履歴で未解消として残ったかを別途定義する。

## 4. 生物学的対応

NA、5-HT、OXT等を警戒・鎮静・親和の単独スイッチとして固定しない。これらは複数系が関与する生物学的接続候補として扱う。

## 5. ξ

未知刺激の内容、未学習カテゴリ、欠測値を `ξ` と呼ばない。有限Bでなお回収されない関係が残るという条件のみを `ξ` として保持する。
