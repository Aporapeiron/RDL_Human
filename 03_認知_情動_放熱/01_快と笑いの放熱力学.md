# 01_快と笑いの放熱力学

*RDL Human / T3 / DRAFT v1.4*  
*Human固有仮説 / Core v2.3同期*

## 0. 位置づけ

本文書は「快」と「笑い」を、予測・解釈の更新、緊張の変化、身体反応、社会同期の関係として記述するHuman側の仮説モデルである。

> **本稿の「熱」「放熱」は心理・神経・身体負荷をまとめて扱う操作的比喩であり、物理熱でもCore `H` そのものでもない。**

Core `H` を使う場合は、`E = Δ(F,F')` のうち何が未解消として履歴的に残ったかを別途定義する。

## 1. 快の仮説

快を「誤差がゼロだから発生する」と固定せず、次の複合として扱う。

```text
RIB_B
↓
F / prediction
↓ 後続相互作用
F'
↓
差分の縮小・目標接近・行動成功・身体状態の変化
↓
Human側の快 / 流れ感
```

補助モデルとして、

```text
Pleasure_Human
≈ f(
  mismatch reduction,
  progress,
  controllability,
  bodily state,
  social response,
  novelty,
  learned value
)
```

を置ける。

DA・内因性オピオイド等との対応は生物学的接続候補であり、一対一の因果式として扱わない。

## 2. 笑いの仮説

笑いは少なくとも複数経路から生じうる。

- **再解釈型**：予測外の出来事が、危険ではない別解釈へ急速に移る。
- **同期型**：他者の反応と相互作用し、集団のタイミングや評価が同期する。
- **境界接近型**：禁忌・権威・危険に近い題材で高い緊張が形成され、安全・無害という再解釈が成立する。

```text
RIB_B^event
↓ M_B
F_initial（緊張・不確実性を含む）
↓ context / social response / re-interpretation
F_later
↓
Human側の負荷低下 + 身体表出 + 社会同期
```

旧「突発EFP」「巨大Hを身体から排出」という表現は現行Coreの説明としては用いない。

## 3. タブー・風刺・炎上の分岐

同じ題材でも、

- 関係履歴
- 発話者の役割
- 参加者
- 制度・規範
- 表現形式
- 直前文脈

によって `RIB_B` と `F` が変わる。

安全・自己言及・共有了解等が成立すれば笑いへ、侮辱・脅威・排除として解釈されれば怒りや関係破断へ進む可能性がある。

ここでHuman側の「社会境界」をCore `B` と同一視しない。社会規範・禁忌は **Bで観測する対象側の関係拘束**である。

## 4. 笑いの身体性

呼気、発声、表情、姿勢、筋活動等は笑いの一部である。ただし「認知熱を物理エネルギーとして呼気へ捨てる」とは主張しない。身体表出が覚醒・呼吸・社会応答・主観的緊張の変化とどう結びつくかを検査対象とする。

## 5. 集団力学

笑いは結束にも排除にも使われうる。嘲笑や生贄化を「放熱先」と実体化するのでなく、

```text
shared response
↓
in-group coordination
+ target positioning
+ norm reinforcement
```

という関係変化として記録する。

## 6. 耐久検査

この仮説は、文化・関係性・無害性・身体反応の個人差を変えたとき、どの説明が残るかを検査する。未説明部分を `ξ` の内容として数え上げず、coverage / unresolved として区別する。
