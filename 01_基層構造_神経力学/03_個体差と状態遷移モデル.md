# 03_個体差と状態遷移モデル

*RDL Human / T3 / DRAFT v1.1*  
*Core v2.3同期*

## 1. 目的

探索・安定化・親和・警戒等の **Human側機能変数の組合せ**と、環境・身体・社会的相互作用による状態遷移を記述する。

個体差をDA / 5-HT / OXT / NAの単純な高低組合せで人格型へ固定しない。

## 2. 個体差プロファイル

暫定的に、次のような応答傾向を観測できる。

- 探索へ移りやすい
- 既存状態を維持しやすい
- 社会的接近・関係維持へ重みを置きやすい
- 脅威関連条件へ注意が向きやすい
- 状態切替が速い／遅い
- 回復が速い／遅い

これらは固定人格ではなく、

```text
profile
= f(
  current body state,
  history,
  task,
  social relations,
  environment,
  tools,
  time scale
)
```

として変化するHuman側の観測量である。

新奇領域・未知課題を `ξ` と呼ばない。

## 3. 状態遷移

```text
human SILN
↕ RIB群
↓ Purpose / B_state
RIB_B(t)
↓ M_B(t)
F(t)
↓
Human-side state / action
↓
interaction conditions change
↓
RIB_B(t+Δ)
```

状態例として、平時・探索・警戒・回復などを置ける。

### 平時
現在の課題・身体・社会条件に対して大きな切替を要さず行動できる。

### 探索
新奇性、退屈、目標未達、機会等によって探索行動が増える。

### 警戒
脅威関連のRIB条件により注意・姿勢・行動優先順位が変わる。

### 回復
高負荷状態の後、身体・注意・行動が通常域へ戻る。

## 4. Leap / 再構成

状態切替とCore T1再構成を同一視しない。短期のモード切替は `M_B(t+Δ)` の範囲で記述できる場合がある。

既存の構造断面では繰り返し対応できず、候補展開・検査・選別を経て新しい構造へ移る場合に、

```text
M_Δ → M_B'
```

として再構成を記録する。

`H ≥ θ` を使う場合はCore上のE/H定義を満たす場合に限り、Human側の覚醒・緊張や神経物質濃度をそのまま `H / θ` としない。

## 5. 生物学的接続

DA / 5-HT / OXT / NA等との関連は、各状態・機能に影響する複数要因の一部として検査する。単一物質の値から「探索型」「共感型」等の人格を決定しない。

## 6. 一文圧縮

> **個体差は固定型ではなく、SILNが複数RIBに関与する中で、探索・維持・親和・警戒・回復などの応答傾向が条件依存で現れる動的プロファイルとして扱う。**
