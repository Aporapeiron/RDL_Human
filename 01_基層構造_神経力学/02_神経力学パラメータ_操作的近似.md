# 02_機能力学パラメータと神経物質の操作的対応

*RDL Human / T3 / DRAFT v1.3*  
*Human固有仮説 / Core v2.3同期*

## 0. 目的と分離原則

本稿は、人間の探索・安定化・親和・警戒などを記述する **Human側の機能力学パラメータ**を置き、神経生物学的観測との接続候補を整理する。

```text
Explore / Stabilize / Affiliate / Alert
= Human-side functional variables
≠ Core primitives
```

DA / 5-HT / OXT / NA 等は、これらと一対一対応する数理実体ではなく、生物学的接続候補である。

## 1. Core接続

旧 `EFP → F → E → H → θ` をHuman神経モデルの固定パイプラインとして使わない。

```text
human SILN
↕ bodily / social / environmental RIB群
↓ Purpose / B
RIB_B
↓ M_B
F
↓
Human functional variables
↓
action / attention / learning / recovery
↓
次のRIB条件
```

Core `E / H / θ` は、比較対象と未解消差分が明示できる場合に限って使う。

## 2. Explore

探索・接近・新奇性選好・学習更新等をまとめて記述するHuman側変数。

- 新奇性や未知領域を `ξ` と呼ばない。
- 「退屈」をCore `H` の自発生成として定義しない。
- 低刺激状態で探索行動が増える現象を扱う場合は、`boredom / novelty seeking / action tendency` 等をHuman側指標として別に測る。

## 3. Stabilize

状態維持・衝動抑制・回復・切替コスト等を記述するHuman側変数。

`Stabilize` がCore `E` を減衰させたり `θ` を直接変更するとは定義しない。必要なら、同じ相互作用条件での反応変化として、

```text
RIB_B
↓
attention / action / recovery differences
↓
F / behavior differences
```

を観測する。

## 4. Affiliate

親和・接近・ケア・所属・内集団化等に関わるHuman側変数。

Human文書でいう「自己境界拡張」は心理社会的な対象化・責任・所属の変化を指し、Core `B` の集合演算ではない。

```text
self-model / relation model changes
≠ B_self ← B_self ∪ B_target
```

他者の苦痛・要求への反応を「他者Eを自己Eへ足す」とも置かない。

## 5. Alert

警戒・覚醒・注意資源配分・行動優先順位の変化を記述するHuman側変数。

```text
threat-related RIB conditions
↓
attention / acquisition / action policy change
↓
F / behavior / next interaction change
```

旧 `interp_alert(M_B,EFP)` や「NAがCore θを直接下げる」という式は採用しない。

## 6. Overdrive / Buffer

長期的な高負荷下の出力維持、痛み・苦痛・注意の一時的変調等を記述する補助変数として保持できる。

これらもCore `H/E` を直接操作する変数ではない。

## 7. 生物学的対応候補

神経伝達物質・ホルモンは多重な作用を持つため、次は**研究仮説上の接続方向**としてのみ使う。

- DA系 ↔ 探索・学習・報酬関連の一部
- 5-HT系 ↔ 状態調整・持続・抑制関連の一部
- OXT系 ↔ 社会的関係・親和・文脈依存反応の一部
- NA系 ↔ 覚醒・注意・警戒関連の一部

これらを人格型や単一行動へ直結させない。

## 8. 耐久検査

各パラメータは、課題・身体状態・社会状況・薬理条件・時間幅等を変えたとき、どの観測関係が残るかを検査する。未説明部分は `coverage / unresolved` とし、`ξ` の量として数えない。
