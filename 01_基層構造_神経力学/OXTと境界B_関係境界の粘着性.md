# OXTと境界B：RDL的考察 v0.2

*RDL_Human / T3 / Human固有仮説*  
*ファイル名の「境界B」は履歴上維持 / Core v2.3同期*

## 0. 位置づけ

本稿は、OXT（オキシトシン）と社会的な愛着・親和・内集団化等の関係を、Human側の **関係境界モデル**で整理する仮説文書である。

> **Human側の「関係境界」「自己圏」「内外判定」はCore `B` そのものではない。**

Core `B` はRDLが有限に扱うPurpose・対象範囲・尺度等であり、社会的境界はBによって観測・記述される対象側の関係構造である。

## 1. 仮説の核

OXTを「愛情そのもの」「境界Bを操作するホルモン」と定義しない。

より弱く、

> **社会的対象への注意・親和・記憶・接近・保護・内集団化等の一部に関与しうる生物学的条件を、Human側の関係結合モデルと接続して検討する。**

とする。

## 2. RDL接続

```text
human SILN_A ↔ social RIB群 ↔ SILN_B / group
                  ↓ Purpose / B_obs
               RIB_B^social
                  ↓ M_B^A
                  F_A
                  ↓
Human-side relation model
  closeness / trust / salience / belonging / defense ...
```

旧

```text
EFP → F → B操作 → M_B切り出し
```

および「OXTがB形成閾値を下げ、M_Bを生成・接続する」というCore記号上の定義は採用しない。

## 3. 「関係境界の粘着性」

この語を使う場合、

- 特定他者への接近が反復される
- 記憶・責任・期待が結びつく
- 相手の状態が行動選択へ強く影響する
- 内集団／外集団の扱いが分化する

といったHuman側の関係結合の持続性を指す。

これは `M_B` 同士を物理的に接着する係数でも、Core `B` の濃さでもない。

## 4. 愛着・恋愛・養育

愛着等を一つの「対象M_B」のネットワーク化として固定せず、複数の相互作用履歴、身体状態、記憶、予測、社会的役割が結合した動態として扱う。

```text
repeated social RIBs
↓
F / action / memory / expectation changes
↓
relation pattern stabilizes
```

## 5. 両義性

親和に関連する生物学的条件が、常に普遍的な「優しさ」へ直結するとは仮定しない。内集団化・競合・脅威文脈等との相互作用により、異なる行動が現れる可能性をHuman側の検査対象とする。

## 6. 補助変数

必要ならHuman側で、

```text
social salience
approach tendency
relation persistence
in-group differentiation
recall strength
```

等を置く。これらをCore `B / M_B / F / ξ` と同一視しない。

## 7. 生物学的対応

OXTを含む神経・内分泌系との接続は経験的検証を要する候補である。本稿だけから因果方向・単一作用・人格特性を確定しない。

## 8. 耐久検査

対象関係、文化、性別、身体状態、脅威条件、反復履歴等を変えたときに、どの関係仮説が残るかを検査する。

> **残すべき核は「OXT＝境界ホルモン」という等式ではなく、社会的関係の持続・接近・内外分化を上流条件から検査する視点である。**
