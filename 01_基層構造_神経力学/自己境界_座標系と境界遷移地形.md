# 自己境界・座標系と境界遷移地形

*RDL_Human / T3 / DRAFT v0.2*  
*Core v2.3同期*

> **注意**  
> 本稿は自己視点・場の捉え方・メタ認知を整理するHuman側の仮説であり、診断名・人格分類ではない。離人感等の臨床概念との接続には別途検証が必要である。

## 0. 最短要約

人間の認知差の一部を、固定タイプではなく、

- 自己を中心に記述する
- 自己も場の一要素として記述する
- 両者を状況に応じて切り替える

という **Human側の座標モデル**として記述する。

旧版ではこれをCore `B` の選択・遷移として直接表現した。現行では、心理的な自己境界・視点・座標モデルとCore `B` を分離する。

## 1. Core Bとの区別

```text
Core B
= RDLが有限に扱うためのPurpose / 問い / 対象範囲 / 尺度 / 時間断面

Human self-boundary / viewpoint
= 人が自己・他者・場をどうモデル化しているかという観測対象
```

Human側の視点変化は、Core `B` を変えなくても同一B内の状態変化として観測できる。逆に、研究者が視点変化を比較するため観測範囲やPurposeを変えればCore Bも変わる。

## 2. 自己中心座標

自己を記述上の中心として、出来事を「私に何が起きたか」から組み立てる傾向。

```text
self-model → world / others / events
```

## 3. 場包含座標

自己も他者・身体・感情・出来事と並ぶ一要素として記述する傾向。

```text
field = {self-model, body, emotion, others, events}
```

「自己が消える」のではなく、記述上の特権的原点でなくなるというHuman側の仮説である。

## 4. 俯瞰と離人の区別

表面上どちらも自己を対象化することがありうるが、

- 身体感覚との接続
- 主体感
- 情動との接続
- 状態遷移の制御可能性
- 生活上の支障

等を別変数として扱う。

俯瞰性から臨床状態を推定しない。

## 5. 境界遷移地形

「境界遷移地形」という名称はHuman側の比喩として残す。

```text
viewpoint A ↔ viewpoint B
```

について、

- どちらへ移りやすいか
- どれだけ滞在するか
- 戻りやすいか
- 情動強度や疲労でどう変わるか

を記述する。

これはCore `B` 間遷移確率ではない。

## 6. 測定仮説

自己申告ラベルだけでなく、同一場面への質問の仕方を変えたときの回答構造を比較する。

例：

```text
あなたはどう感じますか
この場では何が起きていますか
第三者から見たら何が起きていますか
```

観測するのは、自己をどこに配置するか、関係をどこまでモデルへ入れるか、切替コストがどう変化するかである。

## 7. RDL接続

```text
human SILN
↕ interaction RIB群
↓ fixed research Purpose / B
RIB_B
↓ M_B
response / self-report F
↓
Human-side viewpoint model を推定
```

推定された座標モデルにもcoverage限界があり、モデル外のものを自動的に `ξ` の値として数えない。

## 8. 一文圧縮

> **自己境界・座標モデルはCore Bではなく、人間が自己と場をどう配置して記述・経験するかを比較するHuman側の仮説であり、重要なのは固定類型より視点間の可動性と統合度である。**
