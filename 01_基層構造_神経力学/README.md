# 01_基層構造_神経力学

*RDL Human / T3 / Core v2.3同期*

## 一文定義

> **人間というSILNを、変化速度の異なる身体・神経・習慣・信念・即時認知の結合として有限に記述し、反応特性と状態遷移を調べるHuman固有仮説群。**

## 適用規律

4層や神経力学パラメータは、人間の実体を四分割したCore構造ではない。用途に応じて引いたBのもとで得る **時間スケール別の構造断面モデル**である。

```text
human SILN ↔ bodily / neural / social RIB群
             ↓ Purpose / B
          M_B / RIB_B
             ↓
             F
```

- 人間そのものを `M_B` と同一視しない。
- Human側の「自己境界」は心理・社会モデルであり、Core `B` と同一ではない。
- 「熱」「覚醒」「探索圧」等はHuman仮説変数であり、Core `H` と自動同一視しない。
- DA / 5-HT / OXT / NA 等との対応は操作的候補であり、一対一の因果同定ではない。
