# 同一性慣性と発達的統合・解離

*RDL_Human / T3 / DRAFT v0.2*  
*Core v2.3同期*

> **注意**  
> 本文書は自己状態・同一性・発達的統合を扱う仮説メモであり、解離性同一性障害（DID）、幼児期健忘、離人感等の診断基準・原因・治療を確定する文書ではない。臨床概念との接続には別途検証が必要である。

## 0. 最短要約

人間の自己表現は状況に応じて変化するが、それを「複数のCore `M_B` が人格として切り替わる」とは定義しない。

> **人間というSILNについて、異なる相互作用条件のもとで異なる自己表現・行動・記憶アクセスが立ち上がり、それらを時間方向に結ぶ統合関係が存在するのではないか。**

この低速な統合傾向をHuman側で暫定的に **同一性慣性** と呼ぶ。

## 1. Coreからの出発

```text
human SILN
↕ social / bodily / environmental RIB群
↓ Purpose / B
M_B(t) / RIB_B(t)
↓
F(t) / action / self-report / memory access
```

`M_B` は人格そのものではない。状況ごとの自己状態は、同じSILNについての相互作用・構造断面・行動状態の違いとして記述する。

旧 `B → M_B + ξ`、`EFP → F → E → H → θ` の一列式は本稿の標準形として用いない。

## 2. 日常的な状態差

仕事、家族、友人、危険、休息などで、

- 注意
- 行動
- 語彙
- 自己記述
- 記憶アクセス
- 身体状態

が変わることはありうる。

これを直ちに別人格や別 `M_B` の存在論へ結びつけず、条件依存の状態差として扱う。

## 3. 同一性慣性

Human側の同一性慣性を、

- 自己史の連続性
- 記憶の相互アクセス
- 行為主体としての帰属
- 身体感覚との接続
- 状態間の移動可能性
- 他者からの連続的な参照

等を時間方向に結ぶ関係として仮置きする。

```text
state A ↔ state B ↔ state C
     \      |      /
      identity-integration relations
```

これはCore Primitiveではない。

## 4. 解離に関する仮説の身分

DID等を「統合されるはずのM_Bが分裂した」と断定しない。

仮説として検査するなら、

- 状態間結合度
- 記憶アクセス
- 主体帰属
- 状態遷移コスト
- 文脈依存性
- 再統合可能性

等を観測候補とする。

医学的説明とRDLモデルを同一視せず、RDLはあくまで関係の記述枠として使う。

## 5. 発達的形成

幼少期の環境については、

- 安全性
- 予測可能性
- 養育者応答
- 資源回復可能性
- 探索コスト
- 失敗後の修復可能性

等の反復相互作用条件が、長期的な行動・予測・関係形成へ影響する可能性を検査する。

```text
repeated RIB conditions
↓
learning / action / memory changes
↓
longer-timescale pattern
```

強い刺激や心理負荷をCore `H` と同一視しない。

## 6. 幼児期健忘

「自己史座標が未形成だから幼児期健忘が起きる」と因果確定しない。自己概念・言語・記憶システム・時間表象等との関連を検討するHuman側の候補仮説として保持する。

通常の幼児期健忘と解離性記憶断絶を同一視しない。

## 7. 適応と後の拘束

ある環境で有効だった状態依存の反応が、環境変化後には自由度を狭める場合がある、という一般仮説は保持する。

```text
past interaction condition
↓
locally useful response stabilizes
↓ environment changes
same response persists
↓
current mismatch / restricted options
```

## 8. 一文圧縮

> **同一性慣性とは、複数人格や複数M_Bを前提にせず、人間SILNの状態差を時間方向に束ねる自己史・記憶・主体帰属・身体感覚・他者関係の統合傾向を記述するHuman側仮説である。**
