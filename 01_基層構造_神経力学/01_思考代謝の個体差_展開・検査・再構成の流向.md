# 思考代謝の個体差
## ― 展開・検査・再構成の流向 ―

*RDL_Human / T3 / DRAFT v0.2*  
*Core v2.3同期*

## 0. 位置づけ

本稿は、RDL T1の展開・検査・選別・再構成を人間の思考へ試験適用し、思考の個体差を固定タイプではなく **工程ごとの流れやすさ**として記述するHuman固有仮説である。

人間や思考能力そのものを `M_B` と同一視しない。

```text
human SILN
↕ task / tool / other people / environment RIB群
↓ Purpose / B_think
M_B / RIB_B
↓
F / action / candidate models
↓
Human-side thinking profile
```

思考プロファイルはCore記号ではなく、観測された工程傾向をまとめる補助量である。

## 1. 基本仮説

思考は少なくとも、次の操作が連結した過程として記述できる。

```text
対象SILN / 問題を対象化
↓
展開
↓
関係候補の拡張
↓
構造候補の抽出
↓
論理・反例・条件変更による検査
↓
残存関係の選別
↓
再構成 M_Δ → M_B'
↓
必要なら再展開
```

ここで「SILN展開」はSILNをBから生成することではなく、既に対象化したSILNについて、現在の有限記述を広げて候補関係を露出させるT1操作を指す。

## 2. 思考工程

### 2.1 展開

何が支えるか、何と接続するか、条件を変えるとどう動くか、別尺度で何が見えるかを広げる。

### 2.2 関係抽出

候補群の中から、反復・依存・相互作用・保存される接続を拾う。

### 2.3 構造圧縮

異なる対象間に共通する関係配置を有限モデルとして仮置きする。

### 2.4 論理検査

必要条件・十分条件・矛盾・反例・推論接続を局所的に検査する。

### 2.5 耐久検査

Durability Modulesを用い、条件・B・関係・Function契約等を変えて、維持域・変形域・破断域を測る。

### 2.6 再構成

残存関係から候補 `M_Δ` を作り、検査・選別を経て必要なら `M_B'` へ移る。通常の時間経過は `M_B(t+Δ)` とし、`M_B'` は再構成後の構造に限定する。

### 2.7 表象変換

図、数式、文章、比喩、空間表現、時間系列など、**同じPurpose / Bのまま記述形式だけを変更する場合はCore B変更とは呼ばない。**

Purpose・対象範囲・尺度・時間断面等を変更した場合のみ、Core `B` の変更として記録する。

### 2.8 時間統御

短期・中期・長期の状態を同時に保持し、異なる時間幅のRIB_B・構造変化を比較する。

### 2.9 自己適用

自分が使っている理論・判断基準・思考法そのものをSILNとして対象化し、展開・検査・再構成へ戻す。

### 2.10 工程切替

広げる／検査する／止める／再構成する等の工程を、状況に応じて切り替える。

## 3. 思考プロファイル

```text
P_think = {
  expansion,
  relation extraction,
  structural compression,
  logical inspection,
  durability inspection,
  reconstruction,
  representation shift,
  time coordination,
  self-application,
  process switching
}
```

`P_think` は人格の固定値ではない。

```text
P_think
= f(
  task,
  skill,
  fatigue,
  safety,
  time constraint,
  tools,
  collaborators,
  social environment
)
```

と考えるHuman側の観測モデルである。

## 4. 高記録密度個体の利用

「天才」を自然種として分類するのでなく、草稿・失敗・修正・放棄案などが多く残る人物を、**思考工程を復元しやすい高記録密度事例**として扱う。

完成成果から人格本質を逆算せず、どの工程がいつ機能し、どこで破断し、どの道具・他者・環境が関与したかを追う。

## 5. 一文圧縮

> **思考の個体差とは、人間そのものの固定タイプではなく、特定の課題・環境・相互作用条件のもとで、展開・抽出・検査・再構成などの工程へどのように流れやすいかというHuman側の動的プロファイルである。**
